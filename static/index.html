Ejercicio 19. Transporte urbano

Un vehículo experimental registra su velocidad durante los primeros siete segundos. Estimar la distancia recorrida integrando \(v(t)\).

\[d=\int_0^7 v(t)\,dt,\qquad d_{\text{mi}}=\frac{1}{3600}\int_0^7 v(t)\,dt\]

\[T=h\left[\frac{f_0+f_n}{2}+\sum_{i=1}^{n-1}f_i\right]\]

Simpson combinado para \(n=7\): Simpson \(1/3\) en \(0\!-\!4\) y Simpson \(3/8\) en \(4\!-\!7\).

Procedimiento

  1. Se identifican \(t\) en segundos y \(v\) en mi/h.
  2. La integral de \(v(t)\) respecto de \(t\) entrega mi/h·s; se divide entre 3600 para obtener millas.
  3. Se aplica trapecio compuesto y Simpson combinado.
Código Python usado
def trapz(y, h):
    return h * (0.5*y[0] + 0.5*y[-1] + sum(y[1:-1]))

def simpson13(y, h):
    n = len(y) - 1
    s = y[0] + y[-1]
    for i in range(1, n):
        s += (4 if i % 2 == 1 else 2) * y[i]
    return h * s / 3

def simpson38(y, h):
    n = len(y) - 1
    s = y[0] + y[-1]
    for i in range(1, n):
        s += (3 if i % 3 != 0 else 2) * y[i]
    return 3 * h * s / 8

d_trap = trapz(v, h) / 3600
d_simpson = (simpson13(v[:5], h) + simpson38(v[4:], h)) / 3600

Ejercicio 20. Ensayo de elasticidad

Una banda elástica es estirada y se mide la fuerza en distintos desplazamientos. Calcular el trabajo de la fuerza.

\[W=\int_0^{2.8} F(x)\,dx\]

\[W_{\text{trap}}=h\left[\frac{F_0+F_n}{2}+\sum_{i=1}^{n-1}F_i\right]\]

Simpson combinado con \(n=7\): \(4\) subintervalos \(1/3\) y \(3\) subintervalos \(3/8\).

Procedimiento

  1. Se tabulan \(x\) en pulgadas y \(F\) en libras.
  2. La integral entrega lb·in; se convierte a joules con \(1\ \text{lb}\cdot\text{in}=0.112984829\ \text{J}\).
Código Python usado
W_trap = trapz(F, h)                 # lb*in
W_simpson = simpson13(F[:5], h) + simpson38(F[4:], h)
W_trap_J = W_trap * 0.112984829
W_simpson_J = W_simpson * 0.112984829

Ejercicio 21. Perfil topográfico

A partir de una gráfica de altura respecto de posición, estimar el área bajo el perfil entre \(x=1\) y \(x=10\); registrar las coordenadas digitalizadas.

\[A=\int_1^{10} y(x)\,dx\]

Con \(n=9\), Simpson combinado: Simpson \(1/3\) en los primeros 8 subintervalos y trapecio en el noveno.

Procedimiento

  1. Se usan coordenadas digitalizadas ilustrativas del documento.
  2. Se calcula trapecio compuesto y Simpson combinado; la precisión depende de la digitalización.
Código Python usado
A_trap = trapz(y, h)
A_simpson = simpson13(y[:9], h) + (y[8] + y[9]) * h / 2

Ejercicio 24. Diseño de una trayectoria

Representar una cardioide paramétrica con \(b=5\) y estimar su longitud entre \(t=0\) y \(t=2\pi\).

\[x(t)=2b\cos t-b\cos 2t,\qquad y(t)=2b\sin t-b\sin 2t\]

\[L=\int_0^{2\pi}\sqrt{[x'(t)]^2+[y'(t)]^2}\,dt\]

Para esta cardioide, \(\sqrt{x'^2+y'^2}=4b\sin(t/2)\), por lo que \(L=16b\).

Código Python usado
t = np.linspace(0, 2*np.pi, n+1)
x = 2*b*np.cos(t) - b*np.cos(2*t)
y = 2*b*np.sin(t) - b*np.sin(2*t)
dx = -2*b*np.sin(t) + 2*b*np.sin(2*t)
dy = 2*b*np.cos(t) - 2*b*np.cos(2*t)
rapidez = np.sqrt(dx**2 + dy**2)
L_trap = trapz(rapidez, h)
L_simpson = simpson_combined(rapidez, h)
L_exacta = 16*b

Ejercicio 25. Energía gravitatoria

Estimar la variación de energía potencial de un satélite de 500 kg elevado a 800 km. No se asume \(mgh\) como exacta: se usa \(g(y)=g_0R^2/(R+y)^2\).

\[\Delta U=m\int_0^h \frac{g_0R^2}{(R+y)^2}\,dy =m g_0\frac{Rh}{R+h}\]

Comparación aproximada de gravedad constante: \(\Delta U_{\text{aprox}}=m g_0 h\).

Código Python usado
y = np.linspace(0, h, n+1)
g = g0 * R**2 / (R + y)**2
integrando = g
dU_trap = m * trapz(integrando, h)
dU_simpson = m * simpson_combined(integrando, h)
dU_exacta = m * g0 * R * h / (R + h)
dU_constante = m * g0 * h

Ejercicio 27. Geometría de un objeto alargado

Con datos de diámetro a lo largo del eje, estimar el volumen y discutir la diferencia entre la fórmula simplificada y el área real de revolución.

\[V=\pi\int_0^{12} r(z)^2\,dz,\qquad r(z)=\frac{d(z)}{2}\]

Superficie simplificada: \(S_{\text{simple}}=2\pi\int r\,dz\).

Superficie geométrica de revolución: \(S=2\pi\int r\sqrt{1+(r')^2}\,dz\).

Código Python usado
r = d/2
V_trap = np.pi * trapz(r**2, h)
V_simpson = np.pi * simpson_combined(r**2, h)
S_simple = 2*np.pi * trapz(r, h)
dr = np.gradient(r, z)
integrando_geom = 2*np.pi*r*np.sqrt(1 + dr**2)
S_geom = trapz(integrando_geom, h)
